# Sauzze's Scoop bucket

```powershell
scoop bucket add sauzze https://github.com/Sauzze/scoop-bucket
scoop install sauzze/sauzzedeck-pro
```

[SauzzeDeck Pro](https://github.com/Sauzze/agentdeck): a control pad on your
phone for the coding agents in your terminal. The manifest is updated
automatically with each release.
